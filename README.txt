# 영어 학습 배틀 3D (PUBG 스타일)

실행:
1. index.html을 더블클릭으로 엽니다. (three.min.js 포함되어 인터넷 없어도 실행됨)
2. [🎓 기본 훈련] 또는 [전장에 투입!] 클릭 → 화면 클릭으로 마우스 잠금 (Esc 해제)
3. WASD 이동 · Shift 달리기 · 마우스 시점 · 클릭 발사 · 우클릭 정조준
4. R 재장전 · H 구급상자 · F 줍기 · Tab 장비창 · 1/2/휠 무기교체

다른 사람에게 공유하기:
- 이 폴더 전체(index.html, three.min.js, player.js, question.js, reward.js, ui.js, weapon.js)를 그대로 ZIP으로 압축해서 전달하세요.
- 받는 사람은 압축을 풀고 index.html만 열면 됩니다. 설치 불필요.

기본 훈련 (배그식 튜토리얼):
- 시작 화면의 [🎓 기본 훈련]을 누르면 훈련장으로 이동합니다.
- 왼쪽 "기본 훈련 BASIC TRAINING" 패널에 미션이 순서대로 표시됩니다.
- 1 이동하기 → 2 시점 조작 → 3 달리기 → 4 사격하기(전방 표적 5발 명중)
  → 5 재장전(R) → 6 무기 바꾸기(2/휠, 강화 소총 지급) → 7 정조준(우클릭 2초)
  → 8 아이템 줍기(F) → 9 구급상자(H) → 10 영어 문제 풀기
- 아직 배우지 않은 행동(사격·재장전·교체·조준·줍기·회복)은 잠겨 있고 시도하면 안내가 나옵니다.
- 미션을 마치면 "✓ 미션 완료", 8단계 수료 시 "🏆 훈련 완료!" → [전장에 투입!]
- 수료 기록은 브라우저에 저장되어 시작 화면에 표시됩니다.
- 훈련 패널의 [전장으로 이동 »]은 바로 실전으로, [✕ 그만두기]는 메인 화면으로 나갑니다.
  (영어 문제 풀이 중에도 그만두기로 나갈 수 있습니다.)

게임 규칙:
- HP 100
- 좀비 웨이브 전멸 → 영어 문제 (정답 위치 매번 셔플, 3마리부터 어려운 문제 우선·제한시간 30초→25초→18초 단축)
- 정답 → 그 자리에서 멈추고 보상 3종 중 1택 (사진·이름·능력 표시)
- 오답 → HP -20
- 구급상자(H) → HP +40
- 좀비는 계속 다가오고 가까워지면 공격 · 피격 시 화면 테두리 적색 점멸
- 시간이 지날수록·웨이브가 오를수록 좀비 수·이동속도·공격력·체력 증가
- 2웨이브부터 작고 빠른 대시 좀비(주황색 눈, 0.7초마다 공격) 가끔 출현
- 누적 10마리 처치 → 거대 좀비 보스 웨이브 → 마지막 문제 → MISSION CLEAR
- 흰색 안전구역 밖에서는 HP 감소 · 헤드샷 2배 데미지
- 보급 저격총: 몸통 90 · 헤드샷 2배(180), 단발 고데미지
- 헬멧/방어구는 3D 외형과 피해감소에 반영, 조준경은 우클릭 3배줌

파일:
- index.html: 3D 캔버스 + Three.js 로드 (로컬 three.min.js 우선)
- three.min.js: Three.js r128 로컬 복사본 (오프라인 실행용)
- player.js: 3D 월드/마을/안전구역 + TPS 플레이어 + 인벤토리/입력/오디오
- weapon.js: 총기/트레이서/적 3D 메시 + 부착물 성능
- reward.js: 보급품 룰렛/연출/지급
- ui.js: PUBG식 HUD/나침반/미니맵/인벤토리/문제모달/결산
- question.js: 문제은행 (원문 확인 가능한 내용만 사용) + 난이도/시간 설정(QUIZ_CONFIG)
